# 青屿产品讨论

更新时间：2026-10-28。

## 当前保留

- 月下水庭背景：远山、薄雾、湖水、暖灯与石台。
- 人物使用项目内的透明待机、御剑离场视频，不再引用 OSS。
- 运行场景所需的 Vue、TypeScript、Rsbuild、全局样式与代码检查工具。

## 本轮清理

移除头部、导航卡片、导航编辑、工具页面、旧星空背景、路由、本地导航仓储与自动网站图标能力，删除对应依赖和数据测试。页面仅保留背景与人物。

## 人物动画预览

- 打开页面直接循环待机，已移除入场视频与相关逻辑。
- 点击“收起人物”播放御剑离场；离场结束只留背景，并提供“召回人物”恢复待机。
- 离场通过 16:9 画布缩放，显示上限 960×540，小屏继续等比缩小，避免放大 1280×720 的原视频。
- 待机独立保留原本右下角定位，桌面高度 `min(52dvh, 440px)`，600px 以下屏幕高度 `min(34dvh, 280px)`。阶段切换保留短过渡。
- 系统减少动态效果时直接显示静态待机；播放失败或受限时提供重试与手动播放。

## 待继续讨论

- 网站类型和目标用户尚未确定；专注陪伴空间仅为讨论方向。
- 人物更生动的待机与交互动作。

待机与御剑离场已接入预览，其余待讨论内容后续按用户明确任务推进。
