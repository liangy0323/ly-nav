# 青屿产品规划

更新时间：2026-10-27。本文记录已确定的页面需求与待定事项，随产品讨论持续补充。

## 产品方向与现有基础

- 面向开发者，提供常用网站导航与开发工具入口。
- 默认黑色主题，使用星空、太阳系背景和右下角透明修仙角色。
- 已封装 `starry-background`、`character-companion` 和 `resource-card` 业务组件。
- 导航链接与开发工具共用资源卡片，内置导航清单已确定，首批工具为建议清单、待确认。

## 头部布局（已确定）

## 导航数据与本地管理（已实现）

- 安装 Dexie 作为 IndexedDB 基础操作库，数据库名为 `qingyu`。
- 首次进入先显示八张卡片的初始化 loading 占位；事务检查初始化标记，无数据时写入上述默认导航，再从数据库查询显示。
- 初始化标记和默认数据在同一事务内提交，避免重复初始化或失败后出现半份默认数据。
- 导航列表始终从 IndexedDB 读取并订阅变化，不直接渲染默认配置数组；本地新增、修改或删除后由数据库查询刷新列表。
- 用户主动删光导航后展示空状态，再次进入不自动补回默认项。
- 支持新增、查看列表、编辑、删除；删除在卡片内二次确认。网站名称和地址必填，描述与图标地址可选。
- 网站和图标地址支持 HTTP/HTTPS，图标留空时按域名自动获取，加载失败使用卡片首字；编辑采用页面内表单，不占用后续设置抽屉。
- 导出按钮读取数据库当前完整列表，下载 JSON，包含格式标识、版本、导出时间和导航记录；导入另行规划。
- 数据库不可用时显示错误与重新加载入口，不用内存默认列表掩盖持久化失败。
- 数据仅保存在当前浏览器、当前站点来源；当前没有云端同步。

## 首批开发工具（建议，待确认）

以实现范围清楚、日常开发实用、可在浏览器本地处理为筛选原则。
以下优先级属于开发建议，不代表已经确定全部实施，也不代表已经验证使用频率。

| 建议顺序 | 工具        | 首版功能边界                                                                      | 主要使用场景                   |
| -------- | ----------- | --------------------------------------------------------------------------------- | ------------------------------ |
| 1        | JSON 格式化 | 校验、缩进格式化、压缩、复制结果；不扩展 JSONPath、Schema 或代码生成              | 查看接口响应、排查配置语法     |
| 2        | 时间戳转换  | 秒/毫秒时间戳与日期互转、当前时间戳、明确显示本地时区或 UTC                       | 接口联调、日志排查             |
| 3        | 编码解码    | URL 参数编码/解码、UTF-8 文本与 Base64 互转；清楚区分两种编码方式                 | 处理回调参数、链接和编码文本   |
| 4        | UUID 生成   | 生成 UUID v4、单个或有限数量批量生成、一键复制                                    | 测试数据与唯一标识             |
| 5        | 二维码生成  | 文本或链接生成二维码、预览、下载 PNG；首版不做图片识别、Logo 嵌入或美化           | 手机打开调试链接、传递短文本   |
| 6        | JWT 解析    | 解析三段式 JWT 的 Header/Payload，展示 exp/iat/nbf 等时间字段；明确标注未验证签名 | 查看登录令牌字段、排查过期时间 |

### 建议的实施边界

- 先实现 JSON、时间戳、编码解码，再补充 UUID、二维码和 JWT 解析。
- 输入文本在浏览器本地处理，首版不上传工具输入，也不默认保存输入历史。
- 优先采用浏览器原生能力；二维码生成可选择成熟的浏览器端库，具体依赖在实施时决定。
- 共用输入、结果、复制、清空及错误提示的交互习惯，但只在真实复用出现后抽取公共组件。
- JSON 转换需防止大整数被静默改写；编码解码需支持中文并提示非法输入。
- 时间戳明确秒/毫秒及所用时区；UUID 使用安全随机源；JWT 解析结果不作为令牌有效性或验签结论。
- 长文本与批量生成设置合理上限，避免阻塞页面；上限数值在实现时确定。
- 工具打开方式待定，尚未选择弹窗、抽屉或独立页面；头部设置抽屉不默认承载工具。
